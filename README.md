# Cómo construir un arnés

El software que rodea a un modelo y lo convierte en un agente gobernable: el bucle, las herramientas, el contexto, las reglas, los validadores, la aprobación humana, los registros y la auditoría, y los patrones de agentes.

**Ver en línea:** https://aaramirez.github.io/arneses/
